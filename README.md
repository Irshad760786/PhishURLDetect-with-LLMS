# PhishURLDetect-with-LLMS
# Dataset
The paper used ~0.6M URLs (178,142 phishing
URLs and 395,738 benign URLs.). There are few places to gather malicious URLs. My recommendation is to do the following:

Phishing URLs
OpenPhish will provide 500 malicious URLs for free in TXT form. You can access that data [here](https://openphish.com/phishing_database.html)
.

Likewise, PhishTank is an excellent resource that provides a daily feed of malicious URLs in CSV or JSON format. You can gather ~5K through the following [link](https://phishtank.org/index.php) .
We use this publicly available [Dataset](https://github.com/Coldwave96/MaliciousUrls-DL/tree/master/IntegratedData)

Benign Data
I gathered benign URL data via two methods. The first was to use the top 50K domains from [Alexa](https://www.alexa.com/topsites/global)

Next I used publicly available [Dataset](https://github.com/Coldwave96/MaliciousUrls-DL/tree/master/IntegratedData)

# Task
We proposed PhishURLDetect: that  performs the finetuning of pretrained LLM’s (RoBERTa and GPT-2) subword tokenizer on the URL corpus. This enables the customed finetuned tokenizer to generate tokens specific to the URL corpus. Thereafter, the custom trained tokenizer is used in place of the LLM’s default tokenizer for generating token embeddings. In addition, PhishURLDetect uses the LoRA technique to finetune the LLM by minimizing the number of trainable hyper-parameters of the LLM. Finally, the token embeddings generated by the LLMs are fed to fully connected neural network (FCNN) classifier to make the final predictions
